# Positiv-Tracker

Persönliche App für Wins, Gedanken, Gesundheit und Gewohnheiten.
Eine Codebasis für Web, iOS und Android (Expo + React Native + TypeScript).

**Live:** https://flafliflo.github.io/positiv-tracker/

## Entwicklung

```bash
npm install
npm run web        # Dev-Server im Browser
npm test           # Unit- und Komponenten-Tests (Jest)
npm run test:e2e   # End-to-End-Tests (Playwright)
npm run lint       # ESLint
npm run typecheck  # TypeScript
```
